¿Qué es una transacción?

Es un conjunto de operaciones que deben ejecutarse como una sola unidad. Si todo sale bien, se confirma. Si algo falla, se devuelve todo al estado anterior.

Ejemplo bancario

Si se descuenta dinero de una cuenta, también debe sumarse en la otra. Si el sistema falla a la mitad, la base de datos debe deshacer la operación.

COMMIT

Confirma definitivamente los cambios realizados durante la transacción.

ROLLBACK

Cancela los cambios y regresa la información a como estaba antes.

Propiedades ACID

PropiedadSignificadoExplicación sencilla
